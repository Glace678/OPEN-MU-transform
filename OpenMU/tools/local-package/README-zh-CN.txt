OpenMU 本地版使用说明
======================

1. 请先把整个 OpenMU-Local 目录解压到 NTFS 卷，例如：
   C:\Games\OpenMU-Local

   为了保护数据库和密钥，启动器要求所在卷支持 Windows ACL。
   exFAT、FAT32 等不支持持久 ACL 的卷不能直接运行本地服务。

2. 双击 OpenMU-Local.exe。首次运行需要设置至少 12 位的管理密码。

3. 服务器就绪后，在启动器中打开“管理后台”，使用用户名 localadmin
   和首次设置的管理密码登录，然后创建游戏账号。客户端没有注册页面。
   创建账号时，重名或数据库保存失败会保留表单并显示错误，成功后才关闭。

4. 游戏存档、密钥、日志和备份都在 Data 目录。更新或移动程序时，
   请保留整个 Data 目录。
   个人游戏设置位于 Data\Keys\game-config.ini；不要用个人配置覆盖
   App\Game\config.ini。经过完整性校验的默认值位于
   App\Game\config.ini.template，启动器会用它初始化个人配置。

5. 数据库、管理后台和游戏服务只监听 127.0.0.1，不向局域网或互联网开放。
   启动器检测到端口被占用时会停止启动，并提示先关闭另一套服务，
   不会自动结束其他程序。不要同时运行两套使用默认端口的 OpenMU。

6. 程序包已在游戏和 PostgreSQL 目录内携带 x64 Microsoft Visual C++
   应用本地运行库，无需另外安装 VC++ Redistributable。相关再发行说明位于
   Licenses 目录。

7. 此版本默认使用单人平衡：普通经验 8 倍，大师经验 5 倍；
   怪物生命、伤害和防御降低，高阶怪物数值额外压缩。
   NPC 买卖、修理、合成等主要金币费用缩小到原来的千分之一，
   正数最低为 1 金币。关键材料、坐骑、技能书和活动门票可用金币购买。
   旧角色的金币、经验和已分配属性不会被强制清空或缩小。
   详细数值和未验收范围见 Solo-Balance.md。

8. 新配置默认全屏，按游戏所在显示器的最高兼容刷新率限帧，关闭垂直同步。
   已保存的个人窗口模式和帧率偏好会保留，可在游戏选项中修改。
   窗口模式不会替你更改 Windows 的桌面刷新率。手柄在游戏中按 Y，
   或在界面中按 View+Start，可打开快捷键键盘；LT/RT 对应界面的 Ctrl/Shift。
   B 可关闭快捷键键盘并清除锁定的组合键。震动可在选项中调整或关闭。

9. 单人配置仅转换一次。首次转换已有数据库前，启动器会创建
   before-solo-v1 备份。旧版本与本版本的 Data 目录不要同时运行。
   单人商城已实现金币兑换商城点数、购买及领取的服务端处理，
   不涉及真实支付；实际客户端购买流程仍需验收。
   全地图通关、全部手柄流程及真实手柄马达仍需要实际游玩验收。

本程序包仅供本机自用。MuMain 游戏素材授权未明确前，请勿对外分发。
