# OpenMU 安卓手机版

此目录包含可直接安装的 ARM64 游戏 APK、GM 管理 APK，以及配套的 Windows 本地服务器。手机需使用 Android 8.0 或更高版本，手机和电脑必须连接同一个可信 Wi-Fi；不要把这些端口转发到公网。

## 第一次运行

1. 在电脑打开 `OpenMU-手机服务器\OpenMU-Local.exe`。服务器包已预选“手机版平衡（标准）”、开启局域网访问，并准备好这一套 APK 专用的本地游戏账号。服务器首次运行时若要求设置管理员密码，它只供电脑端后台使用，手机游戏和 GM 都不会要求或保存这个密码。
2. 以管理员身份运行 `Open-Windows-Firewall.ps1`。它只允许专用网络的本地子网访问 OpenMU 端口，数据库仍只监听 `127.0.0.1`。
3. 在已开启 USB 调试并授权的 ARM64 手机上运行 `Install-APKs.ps1`，或手动安装 `OpenMU-Game-arm64.apk` 和 `OpenMU-GM.apk`。
4. 打开游戏。游戏会直接选择服务器并登录专用本地账号，不显示账号密码页；新账号第一次进入时创建角色即可。当前资源包第一次启动会在应用内部解压约 895 MiB 数据；连同 APK、原生库和升级时的临时文件，建议安装前至少预留 4 GB 内部存储空间。已有旧版时，覆盖安装还可能需要额外空间。
5. 角色进入游戏后打开 GM。GM 会自动连接同一个本地账号，选择在线角色、搜索物品并直接发送，不再有网页后台或管理员登录页。

APK 默认连接 `192.168.215.56`。电脑局域网地址变化后，在两个应用右上角的设置中改成电脑当前 IPv4 地址；游戏连接端口保持 `44406`，GM 地址使用 `http://电脑IP:5080`。

GM 发物品只允许操作这套 APK 对应账号中当前在线的角色；角色离线时不会直接改数据库，以免与游戏中的状态相互覆盖。物品等级和数量会按服务端定义校验，任务物品、角色绑定物品及超出上限的请求会被拒绝。发送按钮会防止重复点击，同一个请求重复到达也只执行一次。

## 云服务器账号

游戏设置的“服务器”区域可以关闭“本地配对免登录”，然后填写云服务器的 IPv4 地址或域名和连接端口。重新进入游戏后使用普通游戏账号登录；Windows 和手机版连接同一台服务器时，角色数据由该服务器统一保存，不在手机上另建一份角色存档。地址只填写主机名，不包含 `http://`、路径或端口。

本地配对仍只允许本机或局域网 IPv4 地址；切换到普通登录后不会发送 APK 的配对账号和密码。GM 应用仍是可信局域网工具，不随这个开关开放公网功能。不要把本地配对服务器直接暴露到公网；云端应使用独立账号配置，并为网页账号操作配置 HTTPS。

启动器“设置”旁的账号图标提供注册、修改密码、忘记密码和账号设置。账号设置里的门户地址与游戏服务器地址独立：填写部署脚本配置的 HTTPS 门户根地址，不含路径、参数或登录信息；本机 HTTP 和明确启用本地配对的可信局域网 IPv4 可用于本地测试。网页会在系统浏览器打开，游戏不会把账号或密码放进链接。门户语言可单独选择，也可跟随游戏语言。

新注册账号会获得恢复码。请妥善保管；忘记密码时需要这份恢复码，成功重置后旧码立即失效并提供新码。旧账号需先用当前密码领取恢复码，不能只凭用户名重置密码。游戏账号注册不会授予后台管理员权限。

## 手机操作

- 左半屏单指拖动：移动；右半屏单击：选中或确认。
- 进入世界后，技能区双击：释放当前技能。
- 世界区双指左右滑：切换技能；双指上下滑或捏合：调整镜头。
- 世界区三指上滑：地图；三指下滑：游戏设置。
- 菜单中单指点击选中或确认；角色选择时先点选角色，再点右下进入按钮。菜单和底部药水栏不触发世界技能手势。
- 普通背包单击查看物品，原地按住半秒使用可用物品或学习技能；要移格时按住后直接拖动。拖出背包松手、加入第二指、失去焦点或切换界面都会取消并放回尚未发送的拖拽物品。此动作不代替商店、交易、仓库或装备栏的专用操作。
- 底部四个药水格单击使用，复用 Q/W/E/R 的物品可用性校验；空格无操作，长按不会连续使用。
- 设置页可切换左手模式，它交换移动区和技能区，并把侧边工具栏移到左侧；不会镜像游戏内的点击坐标。
- “触控与战斗震动”会驱动手机机身反馈；支持震动的外接手柄也会反馈。
- 外接手柄仍可使用。第一次进入游戏前会强制显示完整手势说明，游戏侧边工具栏也能随时重看。教程和设置按钮纵向排列在独立安全区域，不覆盖原生游戏背包的标题和关闭按钮。

## 画面设置

帧率滑块范围为 30 FPS 到设备最高刷新率，最大值会跟随屏幕；渲染比例控制实际 Surface 缓冲分辨率；特效低/中/高会映射到客户端真实渲染等级；边缘安全区避免刘海和圆角遮挡；触控按钮大小、透明度与左右手布局会直接作用于游戏覆盖层。修改画面或服务器设置后重新进入游戏生效。

游戏内选定的界面语言会保存在游戏配置中，手机版设置不会再把它强制改回简体中文。当前语言列表中仍有英语回退和资源缺口；语言可选不代表 NPC、物品、任务及全部界面文本都已完成翻译。

Android 启动器、手机设置与手势教程现已提供这 15 种界面语言：英语、简体中文、繁体中文、日语、韩语、德语、西班牙语、法语、葡萄牙语、俄语、乌克兰语、波兰语、印度尼西亚语、越南语、菲律宾语。启动器跟随 Android 系统语言，账号门户可单独选择语言；这份列表是现有支持集合，不代表全球使用人数前 15 名。教程使用暗色弹窗，内容可滚动，首次进入前仍可打开设置。

开发者可运行 `./Test-MobileLogic.ps1 -ResourcesOnly` 检查全部启动器与门户资源、数组选项、格式参数和转义，无需启动 Gradle。完整移动端测试仍使用不带参数的脚本。

## 数值规则

“手机版平衡”是服务端真实规则，不是旁置配置：普通等级上限 400、转生后大师等级上限 200、每级 5 点；标准/轻松/旅程使用不同经验倍率；掉落、Zen、药水冷却及 +1 到 +15 强化规则均已接入。已有其他规则的数据库不会自动转换，切档前先备份并新建数据库。

## 局域网安全

游戏 APK、GM APK 和随包服务器配置包含同一份随机配对密钥，用它派生本地游戏账号并限制 GM 接口。它实现的是个人可信局域网内的免登录配对，不是面向公网的账号安全方案：不要转发 `44406`、`55901`、`5080` 等端口，不要把这一套 APK 或服务器配置发给不可信的人，手机和电脑只连接可信 Wi-Fi。重新生成密钥并重打包后，旧 APK 将无法操作新包的本地账号。

## 构建与验证范围

APK 使用 Android 调试证书签名，适合本机侧载，不适合直接发布应用商店。构建已验证 Java、ARM64 ELF、NativeAOT 导出、APK v2 签名、服务端单元测试和资源归档完整性。Android 35 模拟器已验证安装、设置下拉选项、保存后重启保持、手势说明和原生 3D 登录画面；原生启动的合成配方资源读取已延后到 SDL 和数据目录初始化之后。模拟器使用 ARM64 转译，不能替代真实手机的性能和触摸手感验收；角色登录、战斗和多端联网需单独记录结果，不由启动成功推断。
