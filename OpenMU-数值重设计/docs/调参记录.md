# 调参与已知限制

日期：2026-09-05。

## 初始模型暴露的问题

第一次完整运行，采样断言 4,949 通过、6 失败。元素法师在 300/400 级、战斗导师在 400 级无法用成长装备稳定刷三怪；对应经济结果也无效。

逐级推进还发现法魔与统率导师的大师阶段存在无法继续刷怪的级段。升级时长此时无意义，不应该继续给出一个看起来漂亮的小时数。

报告生成曾尝试把不可通关的 Infinity 写入 JSON。已经改为明确的 `null` 和卡住等级字段，失败时不会把无穷时长伪装成有限结果。

## 第一轮修正

普通怪线性攻击系数从 0.95 调为 0.78；法师与导师范围技能的单次总伤害及动作预算重新分配。保留原有生存和正向收支断言，没有将死亡样本排除。

这轮解除了生存卡点，但敏弓效率过高，部分法系和导师大师进度比敏弓慢得过多。

## 第二轮修正

敏捷提供的最大动作加速从 65% 收敛到 45%，敏捷护甲系数从 0.24 降至 0.12。这样处理的是敏捷同时贡献伤害、攻速、护甲的多重收益，而不是单独对某个职业施加经验惩罚。

法师、导师适度补充职业伤害和范围副目标预算。近战、体力流、辅助流仍保留各自的恢复、生存和单体差异。

修正后 14 个流派均通过普通 1–400、大师 0–200 的逐级参考刷怪与收支检查。

## 当前观察

- 单个职业最优参考流派之间的成长耗时差距明显小于所有流派之间的差距。
- 更厚的血量和防御能减少脱战恢复时间；因此守护流派的连续刷怪不一定比输出流派慢。这不是用 DPS×HP 乘积刻意拟合出来的结论。
- 400 级成长装备的单怪参考 TTK 约 4–6 秒；三怪包实际逐只死亡，不把总血量简单除以纸面范围 DPS。
- 400 级金币净结余仍较高，适合单人持续养成，但没有证明可以直接作为开放交易服的经济。
- Boss 以卓越成型档位验证；模型中“躲避预警攻击”是一个可调参数，真实预警与躲避机制还没有进入现有游戏。

## 不能忽略的限制

1. 主模型仍然是两种代表流派，不是枚举所有合法加点、装备、技能轮转。极端属性检查证明有界，不证明每种加点都好玩。
2. 装备档位是预算快照，不是已经跑完“从无装备到整套毕业装”的完整随机成长历程。
3. 标准计时用固定同阶普通怪；有地图覆盖清单不等于已经验证真实出生密度、寻路、抢怪和活动规则。
4. 生命药、魔力药使用阈值是模型策略。真实操作、智能助手策略和网络延迟会影响结果。
5. 14×14 PvP 表没有模拟完整控制链、追击、治疗和打断。PvP 不能以该表宣布已完成平衡。
6. 267 个非核心技能有设计预算，但仍需实际效果/大师节点绑定；特殊物品也需要逐件校对。
7. 独立模型通过的断言数量不是“30,000 多个独立集成测试”。其中大部分是职业、装备、等级网格上的重复不变量检查。
8. 原 S6 内容目录来自本地现有 Release DLL 的内存初始化，本次没有重编译原服务端，也没有证明原目录所有未提交改动已包含在该 DLL 中。
9. 代币奖励状态的防重集合是可执行的逻辑模型。正式服应使用有唯一键的持久化奖励记录，并制定保留/清理策略；不能无限将全部历史 ID 保存在单个内存对象中。
10. 所有“长期平衡”结论都需要实际游玩和遥测支持。本版是一套可检查、可复现、可继续接入的候选系统。
