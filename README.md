# OpenMU 自用工作区

本仓库汇总本地工作区的项目源码、修改、文档及辅助工具。

| 目录 | 内容 |
| --- | --- |
| `OpenMU/` | 服务端、管理页面、启动器及测试 |
| `MuMain/` | 游戏客户端、多平台适配、第三方源码及测试 |
| `OpenMU-Android/` | 安卓客户端、GM 应用和构建脚本 |
| `OpenMU-HarmonyOS/` | 鸿蒙客户端、GM 应用和构建说明 |
| `OpenMU-数值重设计/` | 数值设计、实现和验证工具 |
| `loc/`、`_locwork/`、`_zhwork/` | 汉化数据和处理工具 |
| `ui-repair/` | 界面排查和修复工具 |

各项目的构建方式、依赖和许可证见对应目录中的文档。第三方源码按其原有许可证使用。

上传保留工作区目录结构，嵌套 Git 仓库以源码文件形式收录。编译产物、安装包、缓存、本地配对密钥及签名材料不纳入本次源码上传。安卓配对配置需在本地配置，详见 `OpenMU-Android/Build-AndroidPackage.ps1` 和项目说明。
