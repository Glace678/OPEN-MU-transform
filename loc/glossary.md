## 三、入口 / 通用结构
- "Entrance to X" → 「前往 X 的入口」或「X 入口」（简洁优先）
- "X Level N Entrance" → 「X 第N层入口」；"East/West" → 东/西
- "Gatekeeper / Doorkeeper" → 守门人；"Gateway Machine" → 传送装置
- "Entrance to Safe Zone" → 安全区入口

## 七、Buff / 状态
- "increases by / increase" → 提升/增加；"decrease" → 减少；"reduction speed" → 恢复/减少速度
- buff 描述用「攻击力提升」「防御提升」「攻击速度提升」等动宾短句。
- AG/SD/HP/MP 等缩写保留原字母。

## 八、格式铁律（务必遵守）
1. **占位符原样保留**：`%d` `%s` `%0.2f` `%0.2f%%` `%%` `{0}` `{1}` 等必须原样保留、数量与顺序一致。
2. **分隔符原样保留**：
   - questwords 对话：以半角分号 `;` 分句（不同说话人/旁白），`;` 的数量与位置必须保留。
   - buff 描述：以 `/` 分隔多条属性，`/` 必须保留同样数量。
   - master skill tooltip：以 `#` 分行，`#` 必须保留同样数量。
3. **只输出译文**，不写解释、不写原文、不加引号（除非原文带引号）。
4. 一律用**简体字**，不要用繁体字（如：技能/防御/伤害/攻击/装备/游戏/升级，不是 技能/防禦/傷害/攻擊/裝備/遊戲/升級 里的繁体）。
5. **长度限制**：名称类（道具/技能/地图/NPC）务必简短，中文通常 4–8 字；道具名 ≤ 9 个汉字（字段仅约 29 字节 UTF-8）。宁可意译精简，不要逐字硬译。
6. 数字、单位、罗马数字、英文缩写（如 SD/AG/2D/3D、PvP、PvE）保留。
7. 内部地图标识（如 `Atlans2`、`Aida1`、`Kanturu_ruin_island`）：翻译地名部分，**数字、下划线、实例后缀原样保留**（例：`Atlans2`→`亚特兰蒂斯2`）。
8. 语气：系统提示/说明简洁；NPC 对话自然口语。
