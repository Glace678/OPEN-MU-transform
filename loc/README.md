# loc — archived BMD localization pipeline

This directory is an archive of the old `text.bmd` localization pipeline
(Python scripts that exported, chunked and re-applied BMD strings).

It is not part of the current build and ships no finished translations.

The active engine uses the `.resx` / ResxGen pipeline instead; see
[`../MuMain/docs/translation-system.md`](../MuMain/docs/translation-system.md).
